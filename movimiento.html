Movimiento inercial del móvil

Lectura del acelerómetro y giroscopio para estimar movimiento relativo, sin solicitar acceso al GPS[span_1](start_span)[span_1](end_span).

Importante: no calcula una ubicación geográfica[span_2](start_span)[span_2](end_span).

El acelerómetro y el giroscopio no conocen por sí solos la latitud, longitud ni el punto de partida. Al integrar la aceleración, pequeños errores y vibraciones producen una deriva que crece rápidamente. Esta página muestra sensores y una estimación experimental de desplazamiento local, no una posición fiable para navegación[span_3](start_span)[span_3](end_span).

Detenido. Pulsa «Iniciar sensores» y acepta el permiso si el navegador lo solicita[span_4](start_span)[span_4](end_span).

En algunos navegadores no aparece un diálogo de permisos: eso no significa necesariamente que el sensor esté bloqueado[span_5](start_span)[span_5](end_span).

La estimación usa la aceleración lineal que entrega el navegador y una integración numérica simple. Si el dispositivo no la proporciona, no se inventan valores ni se integra la aceleración con gravedad[span_7](start_span)[span_7](end_span).

Gráfica de trayectoria relativa estimada; puede desviarse aunque el teléfono esté quieto[span_8](start_span)[span_8](end_span).

Limitaciones y uso recomendado

  • Mantén el móvil con una orientación estable para que los ejes sean más interpretables[span_9](start_span)[span_9](end_span).
  • El movimiento estimado no es una ruta real ni sirve como coordenada de mapa[span_10](start_span)[span_10](end_span).
  • Para navegación sin GPS se requiere normalmente una posición inicial y ayudas externas, por ejemplo odometría de pasos, brújula, mapas, balizas o visión; aun así, existe deriva[span_11](start_span)[span_11](end_span).
  • Los datos se procesan localmente en esta página y no se envían a un servidor[span_12](start_span)[span_12](end_span).
